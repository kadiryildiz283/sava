# Güvenlik Politikası (Security Policy)

SAVA projesinde güvenlik en yüksek önceliktir.

## 🛡️ Güvenlik Açığı Bildirimi

Eğer projemizde bir güvenlik açığı tespit ettiyseniz, lütfen bunu **kamuya açık bir Issue olarak açmayın**.

Güvenlik açıklarını doğrudan çekirdek ekibe bildirmek için:
- **E-posta**: `security@sava-codec.org` (veya repository maintainer e-postası)
- **GitHub Private Vulnerability Reporting**: GitHub ana sayfasındaki "Security" sekmesi üzerinden özel bildirim açabilirsiniz.

## ⏱️ Müdahale Süreci

1. Bildiriminiz **24-48 saat** içerisinde onaylanacak ve incelemeye alınacaktır.
2. Açık doğrulandığında yama geliştirilip güvenlik sürümü (`PATCH` release) yayınlanacaktır.
3. Güvenlik açığını bildiren araştırmacıya katkısı için teşekkür edilerek sürüm notlarında jenerik paylaşılacaktır.
